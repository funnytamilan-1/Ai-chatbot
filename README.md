# JustAI

A mobile-first AI assistant built with React, Vite, FastAPI, MongoDB, and the Gemini API.

## Project status

This repository was empty when development started. The first implementation is being added incrementally.

## Structure

- `frontend/` React + Vite client
- `backend/` FastAPI service

## Setup

See `backend/.env.example` and the setup instructions added as the project is implemented. Never commit API keys or `.env` files.
